## Findings and fixes

1. **Conflicting project presentation — corrected.** The outline's old summary
   said nine markets were active while its later text described the completed
   41-market release. It also mixed predecessor experiment settings into generic
   next-step instructions. Current settings now live in the workflow's board;
   the outline explains the reusable structure and links historical designs.
   Its size fell from 3,608 to approximately 2,330 words without relaxing the
   existing 3,500-word limit, phase ordering or protected boundaries.
2. **Stale documentation assertions — corrected.** Assertions requiring
   `NOT BUILT` and an obsolete predecessor gate were replaced with current
   publication and fail-closed readiness requirements. Added a small check for
   the three layers, selected-settings table, empty allowlist and explicit
   unresolved scientific criteria. Historical-snapshot checks remain intact.
3. **Gateway unit tests predated discovery adoption — corrected.** Two tests
   expected lower-level valid scope shapes to pass the installed empty
   allowlist. They now explicitly isolate discovery adoption when testing lower
   policy fields. A separate six-operation test exercises the real discovery
   guard and policy dispatch together, without mocking that guard.
4. **Verification limits — retained, not hidden.** Two discovery preparation
   tests remain explicitly skipped because they rebuild a predecessor against
   an already installed successor. Their historical passing reports are not
   counted as fresh evidence. The successful receipt-to-reader paths require
   new generated fixtures bound to the installed integration before a future
   operation can claim that level of verification. No such claim is made here.

No production code change was needed for these reproduced findings. Do not
relax the empty allowlist or old source bindings to make the audit pass.
